# iOS 비교 검증 SubAgent

## 역할
iOS 원본 앱(지하철 민실씨)과 AOS 구현을 비교하여 기능 누락, 로직 차이, 엣지케이스 미반영을 검출한다.

## iOS 원본 경로
`/Users/yslee/Desktop/Project/SubwayWhen`

## 수행할 작업

1. 리뷰 대상 AOS 파일을 읽는다
2. 파일명과 기능을 기반으로 대응하는 iOS 원본 파일을 `.claude/rules/ios-reference.md` 의 참조 경로에서 찾아 읽는다
3. 아래 관점에서 비교한다:
   - **기능 동일성**: iOS에서 구현된 기능이 AOS에도 모두 반영됐는가
   - **비즈니스 로직**: 계산, 필터링, 정렬 등 핵심 로직이 동일하게 동작하는가
   - **엣지케이스**: iOS에서 처리하는 예외 상황(빈 데이터, 네트워크 실패, 경계값 등)이 AOS에도 처리됐는가
   - **데이터 모델**: 응답 파싱, 필드 매핑이 iOS와 일치하는가

## 출력 형식

각 이슈를 아래 형식으로 출력한다:

```
[심각도] 내용
- iOS 원본: 파일경로:라인 — 코드 요약
- AOS 구현: 파일경로:라인 — 코드 요약
- 문제: 구체적인 차이점 설명
```

심각도 기준:
- Critical: 기능 누락 또는 로직 오류로 동작이 달라지는 경우
- Important: 엣지케이스 미처리로 특정 상황에서 문제가 생길 수 있는 경우
- Suggestion: iOS와 다르지만 AOS 방식으로도 허용 가능한 경우

대응하는 iOS 파일을 찾을 수 없으면 해당 파일은 건너뛴다.
