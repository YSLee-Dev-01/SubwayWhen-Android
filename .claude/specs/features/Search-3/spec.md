# Search-3

## 무엇을 하는가
지하철역을 검색하고 저장하는 Search, Search-2에 이어서 개발하는 Spec이야
Search에서 생략한 가장 가까운 지하철역을 보여주는 기능을 개발할거야

1. 위치 권한을 받지 않은 경우
- 가까운 지하철 역의 정보를 확인할 수 있다는 title과 버튼을 표출

2. 위치 권한을 거부한 경우
- Modal로 권한 설정이 되어 있지 않다는 것을 표출

3. 위치 권한을 받은 경우 + 주변에 역이 있는 경우
- 가까운 순서대로 역명을 표출
    - 역명은 이미 만들어진 commonView의 역명을 나타내는 뷰를 사용
    - BG는 해당 노선 색
    - 좌우 스크롤 가능
    
- 새로고침 버튼이 존재하며 새로고침은 5분에 한번만 가능 
    - 5분 전에 누를 경우 팝업 표출
    
- 하단에는 목록으로 확인하기 버튼이 있음
    - 버튼을 누르면 Modal에 현재 위치와 가까운 역 순서대로 표출
    - 왼쪽에는 호선 정보, 그 다음 역정보, 가장 우측에는 km 정보를 표출
    - 셀을 누르면 해당 역을 검색함
    
- 역명을 누르면 해당 역에 대한 실시간 정보를 표출
    - 상행/내선은 왼쪽, 하행/외선은 오른쪽
    - 가운데는 역명이 크게 존재
    - 왼쪽은 역명 대비 살짝 위에 배치
    - 오른쪽은 역명 대비 살짝 아래에 배치
    - 하단에는 상하행 현재 정보 표출
    - 맨 하단에는 닫기, 새로고침, 임시 보기, 추가하기, 신고하기 버튼이 각각 존재
        - 현재는 임시 보기, 신고 하기를 제외하고 연동
    - 닫기를 누르면 역명을 누르기 전으로 변경
    - 새로고침을 누르면 실시간 정보 새로고침
    - 검색하기를 누르면 해당 역명을 검색 한 후 결과가 나온 경우 Modal을 띄움

4. 위치 권한을 받은 경우 + 주변에 역이 없는 경우
- 주변에 역이 없다는 텍스트만 표시
