# Tutorial

## 무엇을 하는가
앱을 처음 사용하는 사용자에게 튜토리얼을 보여주기 위해 사용

## 동작 명세
- 트리거: 앱을 시작할 때 로컬 값을 확인하여 튜토리얼을 보지 않은 경우만 진입
- 결과: 앱이 시작하고 스플레쉬 화면 뒤에 튜토리얼 화면 표시
- 사이드이펙트: 내부 로컬 데이터 값
- 불변 조건: 
- 스플래쉬 이후에 화면이 표출되어야 함
- 튜토리얼 이후에는 홈 화면이 표시되어야 함

## 무엇이 잘못될 수 있는가
- 내부 로컬 값을 불러오지 못할 때 

## 무엇에 의존하는가
### 의존성
- 내부 로컬 데이터

### 제약
-  튜토리얼 이후에는 홈 화면이 표시되어야 함

## Acceptance Criteria
- [x] 튜토리얼 이후에 홈 화면이 표시되는지
- [x] 스플래쉬 이후에 화면이 표출되어야 함
- [x] 튜토리얼을 한번 본 사람은 다시 앱에 진입해도 튜토리얼이 표시되지 않아야 함
