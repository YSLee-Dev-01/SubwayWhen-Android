# Search

## 무엇을 하는가
지하철역을 검색하고 저장하기 위해 사용해
기능이 많이 있으니 여러 단계로 나누어서 개발할거야
우선 검색 기능 및 자주 검색하는 지하철역을 표시하는 기능 부터 개발할거야 

1. 미리 만들어둔 NavigationBar를 사용해서 검색 탭인걸 사용자에게 알려
2. ScrollView를 사용해서 해당 화면을 구성해
3. ScrollView는 3개의 뷰가 있어
    3-1. 가장 위는 TextField가 위치해
    - iOS기준으로 TextField를 사용
    - 플레이스 홀더는 "🔍 검색어를 입력하세요."
    - 누르면 검색 모드로 진입해
    - 검색 모드로 진입한 경우 두번째 (가까운 지하철역 표시)를 표시하지 않고, Result 화면을 표출해
    - 검색어, 결과에 따라서 보여주는 텍스트와 뷰가 달라
    - 검색어가 입력되지 않은 경우:  💬
    - 검색어에 맞는 결과가 없는경우: 검색된 지하철역이 없어요.
    - 결과가 있는 경우 해당 결과를 표시해
    
    3-2. 두번째는 사용자의 위치와 가까운 지하철역을 표시하고 누르면 실시간 데이터를 보여주는 영역이야
    - 이 부분은 나중에 구현할거라 View는 Empty로 처리해줘
    
    3-3. 마지막은 자주 검색하는 지하철역을 표시하는 영역이야
    - 사용자가 지하철역을 누르면 해당역을 바로 검색해
    -> 검색 모드로 진입하는거야
    - firebase를 통해 값을 가져오고, 값을 가져오기 전 초기 값은 아래와 같아
    -   "강남", "교대", "선릉", "삼성", "을지로3가", "종각", "홍대입구", "잠실", "명동", "여의도", "가산디지털단지", "판교"
    - Row에는 2개의 역만 표시해

## 동작 명세
- 트리거: 탭바에서 검색 탭을 눌렀을 때
- 결과: 검색화면에서는 여러가지 액션이 있어
- 현 spec에서는 검색화면의 기본만 구성할거야 (가장 첫문단 참고)
- 사이드이펙트: 네트워크 통신, 로컬 데이터 저장
- 불변 조건: 네트워크 통신, 로컬 데이터 저장에 실패해도 화면은 무조건 표출되어야 함

## 무엇이 잘못될 수 있는가
- 네트워크 에러 -> 기본 처리
- 로컬 데이터 저장 에러 -> 기본 처리
