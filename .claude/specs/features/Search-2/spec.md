## 무엇을 하는가
지하철역을 검색하고 저장하는 Search Feature에 이어서 개발하는 Spec이야
이제 검색된 지하철역을 눌렀을 때 Modal이 나오는데 그 화면을 개발할거야

Modal은 화면 전체를 덮지 않고 일부분만 덮어
하단에는 Modal View가 존재하고, Modal 위에는 작게 일회성으로 실시간 정보를 확인할 수 있는 View가 있어

Modal 화면은 검색 뿐만 아니라 다른 화면에서도 재사용하기 때문에 미리 만들어둔 commonView를 사용해
(없을 경우 제작)

Modal 화면 내부에는 
    - 메인 title
    - 서브 title
    - 호선 명 및 역명
    - 출퇴근 버튼, 중간 종찰역 제거 TF
    - 내선/상행 버튼 , 외선/하행 버튼 
    (2호선만 내선, 외선)
이 존재해

메인, 서브 title은 iOS와 동일해
호선 명 및 역명 또한 배치, 사용법은 iOS와 동일해

상행/하행 버튼을 누르면 로컬 데이터에 저장하는 비즈니스 로직을 가져
상행/하행 버튼을 누르면 입력된 출근/퇴근 값에 맞춰서 값을 저장해
상행/하행 버튼을 누르면 중간 종착역 제거를 저장하는데 콤마를 사용해서 여러개의 역을 저장할 수 있어

상행/하행을 누르면 저장이 완료되었다는 Modal이 표출돼

작게 일회성으로 실시간 정보를 확인할 수 있는 View는 Detail과 연동되는 부분이라 View만 임시로 만들어줘

저장이 완료되었다는 Modal은 
    - 메인 title
    - 서브 title
    - 로띠 View
    - 확인 버튼
이 존재해

그리고 Modal 위에 축하 애니메이션을 송출해

메인, 서브 title은 iOS와 동일해
로띠 애니메이션 또한 iOS의 파일을 그대로 사용하면 돼

확인 버튼을 누르면 Modal을 닫으면 돼

축하 애니메이션도 로띠를 사용하고, iOS와 동일한 애니메이션을 사용해

## 동작 명세
- 트리거: 
1. 검색된 지하철역을 클릭했을 때
2. 상행/하행 버튼을 눌렀을 때
3. 출근/퇴근 버튼을 눌렀을 때
4. 중간 종착역 제거 TF를 눌렀을 때 
- 결과: 
1. 검색된 지하철역을 저장할 수 있는 Modal 화면 표출
2. 상행/하행 버튼을 누를 경우 입력된 데이터를 로컬에 저장
3. 출근 버튼을 누를 경우 퇴근, 퇴근 버튼을 누를 경우 출근으로 변경
4. 중간 종착역 TF에는 콤마를 사용하여 여러 역을 저장할 수 있음 
5. 상행/하행 버튼을 누르면 Modal이 닫히고 저장이 완료되었다는 새로운 Modal이 송출되고, 애니메이션이 보임
- 사이드이펙트: 이미 로드된 검색 결과로 Modal에 필요한 데이터 사용
- 불변 조건: 
1. 검색 결과가 있을 경우 Modal은 성공적으로 표출되어야 함
2. 입력된 정보에 맞게 로컬에 데이터가 저장되어야 함
