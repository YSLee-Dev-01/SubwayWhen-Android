# Edit

## 무엇을 하는가
사용자가 저장한 지하철역을 편집하기 위해 사용한다.
세션은 출근, 퇴근으로 나눔
출근과 퇴근에 맞춰서 지하쳘역을 정렬함
- 출근이 먼저

우측의 버튼을 통해서 스와이프 하면 순서를 변경할 수 있음
순서 뿐만 아니라 출근, 퇴근 세션도 변경할 수 있음

좌측의 - 버튼을 누르면 저장된 지하철 역을 지울 수 있음

하단의 "저장" 버튼을 눌러서 변경된 내용을 저장할 수 있음
저장 전에 뒤로 가기 버튼을 누르거나 back 액션을 취하면
"수정된 지하철역이 저장되지 않았아요.\n저장하지 않을 경우 변경된 내용은\n적용되지 않아요,"
title이 포함된 팝업을 표출하고
"저장", "저장하지 않음", "취소" 버튼을 출력
"저장"은 저장 후 pop
"저장하지 않음"은 저장하지 않고 pop
"취소"는 팝업만 닫음

## 동작 명세
- 트리거: 홈 화면에서 편집 버튼을 눌렀을 때
- 결과: 좌측 삭제 버튼, 우측 순서 옮기기, 저장 버튼, 처음 지하철 로드
- 사이드이펙트: 로컬 데이터
- 불변 조건: 데이터를 로드하지 못하더라도 편집 화면은 표출 되어야 함

## 무엇이 잘못될 수 있는가
- 로컬 데이터를 로드하지 못함

## Acceptance Criteria
- [x] 홈 편집 버튼 탭 시 Edit 화면 진입, 탭바 숨김
- [x] 저장된 역이 출근/퇴근 섹션으로 분리되어 표시 (출근 먼저)
- [x] 좌측 "−" 버튼으로 행 삭제 가능
- [x] 우측 드래그 핸들로 같은 섹션 내 순서 변경 가능
- [x] 우측 드래그 핸들로 다른 섹션으로 이동 시 group 필드가 변경되어 저장됨
- [x] 변경사항이 있을 때만 "저장" 버튼 활성화
- [x] "저장" 버튼 탭 시 LocalDataRepository 에 반영 후 화면 pop
- [x] dirty 상태에서 뒤로가기 시 "저장 / 저장하지 않음 / 취소" 3버튼 다이얼로그 표출
- [x] "저장" → 저장 후 pop / "저장하지 않음" → 그대로 pop / "취소" → 다이얼로그만 닫힘
- [x] 저장된 역이 없을 경우 "현재 저장되어 있는 지하철역이 없어요." 안내 표출, 편집 화면 자체는 정상 렌더링
